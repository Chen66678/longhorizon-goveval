# Public scope and evaluation boundary

This repository contains only the files listed in `allowlist.txt`; the audit
tool checks that published-tree property.

The Public Dev pack contains synthetic tasks with the `LHGE_DEV_` identifier
namespace and `lhge-public-dev-` seed namespace. Their facts, rubrics, and
truth are public for integration and development use.

Formal evaluation instances, answer keys, formal scorers or verifiers, retained
seeds, model prompts and completions, raw provider receipts, credentials, and
internal run records are not included in this repository. The Open Preview is
therefore not a substitute for sealed formal evaluation.
